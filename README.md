## ✨ O que é o AutoHotkey Visual Code?

O **AutoHotkey Visual Code** é uma ferramenta **100% online** que permite criar scripts AutoHotkey através de uma interface visual.

Você configura tudo pelo navegador e o site gera automaticamente o arquivo `.ahk` pronto para uso.

✔ Sem programar  
✔ Sem baixar projeto  
✔ Sem configurar ambiente  
✔ Resultado imediato
